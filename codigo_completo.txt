# Arquitetura dos agentes

Este documento descreve o código atual. A prioridade é o 1v1; comportamento cooperativo em equipes ainda precisa de validação.

## Política e observações

`src/model.py` implementa `Policy`: MLP com duas camadas de 256 unidades e Tanh, três cabeças categóricas independentes (X, Y, chute) e uma cabeça de valor. Usa a inicialização padrão de `torch.nn.Linear`; não há inicialização ortogonal explícita.

O ambiente usa `DefaultObs(pos_coef="auto")`, de HaxballGym. O mapa padrão é `maps/futsal_1v1.hbs`, uma cópia local de futsal-classic com paredes sem bias e damping explícito. Os checkpoints 1v1 disponíveis têm 16 entradas. A dimensão e o formato das observações dependem do builder e do número de jogadores; a definição exata está na dependência instalada.

As ações são bins `[0, 1, 2]` para movimento (−1, 0, +1) e `[0, 1]` para chute (soltar, pressionar). `RepeatKickAction` converte pressão em input 2 do engine, rearmando dentro da janela de ticks; as cabeças da política continuam com duas opções. O exportador grava `repeat_kick`, e a sala rearma entre decisões quando esse campo está ativo. O ambiente converte o eixo X do time azul para o referencial da política.

`NeuralBot` carrega `model.pt` e `meta.json`, com ações greedy por padrão. Treinamento, avaliação interna e torneio amostram ações; essa diferença deve ser considerada na validação.

## Baselines

- `ChaseBot`: persegue a posição atual da bola, adiciona ruído angular (`jiggle=0.25`) e pressiona chute quando a distância é menor que 34. Não prevê interceptação. Uma seed fixa torna a sequência de ruído reproduzível.
- `RandomBot`: ações uniformes, útil como controle básico.

## Self-play

A política controla todos os jogadores vermelhos com compartilhamento de parâmetros. O azul usa uma política congelada. A cada rollout de 64 decisões, escolhe-se um único adversário para todos os ambientes: snapshot aleatório com probabilidade 0.5 quando o pool existe; caso contrário, cópia atual do learner.

Um snapshot é adicionado a cada 20 iterações; o pool contém no máximo 40. A escolha não ocorre por episódio e pode mudar durante uma partida. O pool reduz a exposição exclusiva ao adversário mais recente, mas não garante progresso monotônico nem elimina ciclos.

## Equipes: etapa futura

A coleta já compartilha parâmetros entre jogadores vermelhos, mas o `KickoffSetter` atual só posiciona explicitamente dois jogadores. Observações, resets, recompensas e exportação devem ser validados antes de treinar 2v2/3v3. O gol recebe peso 25 no treinamento atual; não há garantia de que passes, cobertura ou papéis surjam.

Após consolidar o 1v1, comparar treinamento do zero com transferência parcial/fine-tuning. Mudanças na dimensão da observação podem impedir o carregamento direto dos pesos.

A documentação anterior descreve uma versão em Python com throughput limitado, tentativas de behavioral cloning e recompensas densas exploradas sem produzir gols. Esses relatos motivaram a migração para HaxballGym e PPO self-play. Não foram revalidados nesta revisão.

## Estado atual

O código usa o simulador de HaxballGym, PyTorch e uma política pequena em CPU por padrão. Os registros disponíveis mostram aproximadamente 13–14 mil amostras de jogador por segundo numa execução; esse valor depende da máquina, configuração e custo de avaliação. Não há aqui uma certificação de equivalência bit a bit com o jogo oficial.

`training_stats.json`, `models/meta.json`, `models/meta_final.json` e `poc_results.json` contêm resultados de origens/configurações que não estão identificadas de forma consistente. Não devem ser combinados numa única curva ou tomados como prova de convergência. Metadados também podem mudar durante execuções e seleção.

O experimento registrado em `poc_results.json` apresenta forte queda de gols e de atividade ofensiva ao longo de 75 iterações. Sem configuração completa e replicações, isso é um alerta para investigar a recompensa, não uma conclusão causal.

# Protocolo de treinamento e avaliação

Valores conferidos em `src/train.py`. Este documento distingue implementação atual de experimentos propostos.

## Correções na branch gpt

O treino usa por padrão `maps/futsal_1v1.hbs`. Removemos o bias das paredes do mapa original após reproduzir escape da bola para cantos externos; testes verificam rebote nas duas laterais. Isso altera o estádio: uma política exportada deve carregar o mesmo mapa. A equivalência com física oficial não foi certificada.

A tabela mantém os pesos desejados (gol ±25, aproximação 0,6, progresso 0,08), mas usa deslocamento efetivo:

- `MotionPlayerToBall`: projeta o deslocamento do jogador na direção anterior da bola. Jogador preso sem mudar de posição recebe zero, mesmo que o engine reporte velocidade.
- `MotionBallToGoal`: redução assinada da distância da bola ao segmento finito do gol adversário. Um percurso de ida/volta fechado cancela sem desconto.
- Ambos dividem pelo deslocamento livre máximo esperado em uma decisão: acceleration × damping / (1 − damping) × tick_skip. No mapa atual, 21,12 unidades por decisão, em vez do player_max_speed ≈0,119 informado pela dependência.

A ação de pressionar chute agora rearma repetidamente no simulador. A exportação inclui `repeat_kick`; bot.js executa a mesma intenção entre decisões quando esse campo é true. Checkpoints antigos sem esse campo preservam seu comportamento anterior na sala.

`src/repair_bot.py` faz fine-tuning contra Chase e avaliação nos dois lados, com kickoff e resets aleatórios, ações greedy/amostradas, múltiplas seeds de avaliação, vitórias/empates/derrotas por episódio e fração de decisões com bola parada. O treino principal continua com PPO self-play; este experimento curto não comprova convergência. As seeds de seleção não substituem validação independente.

As tabelas `simple`, `simple_progress1` e `previous` permanecem para reproduzir recompensas anteriores. São sinais diferentes da tabela corrigida: pesos iguais não implicam magnitude igual.

## PPO atual

| Parâmetro | Valor padrão |
|---|---|
| Ambientes / jogadores | 512 / 1v1 |
| Rollout / épocas / minibatches | 64 / 6 / 4 |
| Amostras por iteração em 1v1 | 32.768 |
| Tick skip | 8 (~7,5 decisões/s a 60 ticks/s) |
| Discount | meia-vida de 12 s; gamma ≈ 0,99233 |
| GAE lambda / clip | 0,95 / 0,20 |
| Learning rate | 3e−4 → 1e−4, linear |
| Entropia | 0,02 → 0,01, linear |
| Coeficiente de valor / norma máxima de gradiente | 0,5 / 0,5 |
| Limite de episódio | 2.000 ticks = 250 decisões com tick skip 8 |
| Resets de treino | 40% kickoff, 60% estado aleatório (`ball_speed=3`) |

A perda de valor já inclui fator 0,5 antes de receber `VF_COEF`. O GAE trata tanto término quanto truncamento como fim sem bootstrap; revisar essa escolha para timeouts. `--warm-start` reinicia otimizador, schedules e contador. Por padrão, carrega a política e zera a cabeça de valor para adaptar a escala corrigida de recompensa. `--keep-critic` preserva a cabeça de valor quando apropriado. Essa reinicialização não altera os logits iniciais de ação.

## Tabela atual de recompensas

Antes da branch gpt, a tabela padrão era `build_reward("simple")`: gol ±25, aproximação com peso 0,6 e progresso com peso 0,08. Agora o padrão é `corrected`, descrito acima. Os dois termos de velocidade preservam sinais positivos e negativos. Treino e avaliação interna compartilham essa fábrica.

A tabela anterior permanece disponível como `build_reward("previous")` para comparação controlada:

### Tabela anterior

Treino e avaliação interna usam a mesma composição. O multiplicador interno se combina com o peso de `CombinedReward`:

| Termo | Peso externo | Fator interno | Contribuição efetiva |
|---|---:|---:|---|
| `VelocityPlayerToBall` | 0,7 | — | 0,7 × velocidade projetada, normalizada por `player_max_speed` |
| `VelocityBallToGoal` | 1,0 | — | velocidade projetada para a linha do gol adversário / `player_max_speed` |
| `TangentialGoalShotReward` | 3,0 | 3,0 | 9 × deslocamento da bola por decisão, quando os filtros passam |
| `DeltaBreakawayReward` | 2,0 | 2,0 | 4 × max(phi atual − phi anterior, 0) |
| `PenaltyTackleLostReward` | 1,0 | −0,5 | −0,5 quando o evento definido na função ocorre |
| `GoalReward` | 20,0 | ±1 | +20 ao marcar, −20 ao sofrer |

O chute usa deslocamento, não velocidade normalizada: sua escala depende do tick skip. O filtro aceita trajetória projetada na boca do gol **ou** bola já na faixa |y| ≤ 65, e usa proximidade <36 como contato. Não identifica necessariamente um chute efetivo.

A ultrapassagem define posse como ser o jogador mais próximo da bola, sem distância máxima. Só recompensa aumentos da vantagem: perder e recuperar vantagem pode gerar pagamentos repetidos. Não é shaping baseado em potencial com preservação garantida do objetivo.

Não está demonstrado que o gol domine a soma dos termos densos. Medir contribuições acumuladas por episódio e sua relação com gols antes de ajustar pesos. `ShotVelocityToGoal` está definido no arquivo, mas não participa da composição atual.

### Experimento proposto: simplificar

Comparar a tabela atual com uma base de três termos: gol, aproximação do jogador e progresso da bola. Remover inicialmente chute tangencial, ultrapassagem e penalidade de desarme na variante experimental. Calibrar os dois pesos densos usando suas contribuições acumuladas e comparar com orçamento igual de amostras e várias seeds. A variante de três termos foi aplicada ao treinamento. O POC compara as duas variantes.

## Avaliação implementada

- `eval_vs_chase`: a cada 50 iterações e no fim, 128 ambientes × 350 decisões, learner vermelho com ações amostradas, Chase azul com seed 0 e resets de kickoff. Saldo de gols seleciona `model.pt`.
- `src/eval.py`: padrão de 256 ambientes × 600 decisões, NeuralBot greedy; benchmark contra Chase e Random. O indicador chamado “winrate estimada” é proporção dos gols, não taxa de vitória por partida.
- `src/select.py`: torneio de checkpoints em `models/ckpts/` e modelo final; cada par joga nos dois lados, com ações amostradas. Ranking por proporção de gols, desempate por saldo. Não usa TrueSkill nem matriz de vitórias. Promove o vencedor sobrescrevendo `model.pt`; metadados herdados do modelo final podem não descrever a iteração do vencedor.

Esses caminhos usam configurações de ambiente distintas: treino/avaliação interna criam o ambiente explicitamente; benchmark/torneio usam `make_default_env`. Alinhar condições para comparações reproduzíveis.

## Avaliação planejada para consolidar o 1v1

1. Fixar configuração e registrar seeds de treino, cenário e ações; começar com pelo menos três seeds de treino e cinco de avaliação.
2. Avaliar nos dois lados contra Random, Chase sem ruído, Chase com ruído, um defensor e um bot com interceptação, além de snapshots históricos. Os dois últimos bots ainda precisam ser implementados.
3. Reportar gols pró/contra, saldo, vitórias/empates/derrotas por partida, duração e dispersão entre seeds. Identificar explicitamente resultados greedy e amostrados.
4. Comparar variantes de recompensa com orçamento igual; reservar adversários/cenários para validação final.
5. Inspecionar replays e partidas reais para confirmar finalização, defesa e ausência de exploração da recompensa.

Definir duração e limiar de aprovação antes dos experimentos. Um único saldo contra Chase não estabelece consolidação.

## POC curto reproduzível

```bash
uv run src/poc_reward.py --out experiments/minha_comparacao --iters 30 --envs 64 --seeds 0 1 2 --eval-seeds 10 11
```

O POC usa o mesmo checkpoint inicial, seed e orçamento para cada variante; faz fine-tuning contra Chase (não self-play) e avaliação greedy nos dois lados contra Chase com/sem ruído e Random. Grava configuração, hash do checkpoint, contribuições dos termos, cenários controlados e resultados em pasta nova. Não sobrescreve os modelos principais. Os cenários incluem sinais positivos/negativos, gols e trajetórias no simulador com defensor dentro/fora da linha do chute.

Trinta iterações servem para detectar regressões rápidas; não demonstram convergência nem permitem declarar uma tabela vencedora definitiva.

### Alerta encontrado no POC

No ambiente instalado, `futsal-classic` fornece `player_max_speed ≈ 0,11865`. A função de progresso divide por esse valor: um chute livre controlado acumulou aproximadamente 385 de shaping em 13 decisões, além do gol +25. A tabela simples ainda precisa de verificação/correção da normalização antes de treinos longos. Consulte `experiments/reward_simple_poc_20261013/REPORT.md`; o POC curto não demonstrou melhoria da variante simples.

### Variante com progresso 0,08

A tabela padrão passa a gol ±25, aproximação 0,6 e progresso 0,08. `simple_progress1` preserva a variante de progresso 1,0 para comparação pareada no POC.

```bash
uv run src/poc_reward.py --out experiments/comparacao_008 --tables simple_progress1 simple
```

Na trajetória controlada de chute livre, a contribuição ponderada de progresso cai de +385,33 para +30,83. Com defensor na linha, cai de −6,60 para −0,53. Essas são somas sem desconto só do termo de progresso; aproximação e gol são parcelas separadas. Uma decisão com velocidade projetada 3 gera aproximadamente ±2,02 com peso 0,08.

Os geradores de reset de treino agora recebem `--seed` explicitamente. A comparação anterior não controlava esses geradores; a repetição corrigida está em `experiments/reward_progress008_seeded_poc_20261013/`.

Diagnóstico posterior: o saldo 0 × 448 corresponde à mesma derrota de kickoff repetida deterministicamente. O checkpoint 0,08 evita essa sequência, mas leva a bola ao canto e termina por timeout, sem consolidar ataque ou defesa. Veja `experiments/reward_progress008_seeded_poc_20261013/diagnosis_long/REPORT.md`.

## Telemetria do self-play monitorado

O treinador grava `training.jsonl` (uma linha por iteração), `evaluation_cases.jsonl` (cada caso), `evaluations.jsonl` (painel completo) e `live.json` (heartbeat/estado). Configuração, revisão Git e hash do warm-start ficam em `config.json`. `initial_policy.pt` congela o adversário neural de referência.

Avaliação padrão: 16 ambientes × 400 decisões, seeds 1701/1702, ambos os lados, kickoff e estados aleatórios, cinco adversários, learner greedy. Cada caso recebe peso igual na pontuação de seleção. Na ausência de episódios completos a pontuação é desconhecida, não zero. Avaliação inicial e a cada 50 iterações; snapshots de self-play continuam a cada 20 iterações. A avaliação preserva o estado RNG do PyTorch do treino.

Métricas PPO: perdas de política/valor, entropia somada das três cabeças, KL aproximada, fração de clipping e variância explicada calculada com valores do rollout. Métricas de jogo: gols, episódios completos, bola parada (deslocamento <0,01 por decisão), contato e pressão de chute dentro de 24,8 unidades. A frequência de bola parada inclui kickoffs normais e não mede sozinha travamento. A pontuação não classifica quem deu o último toque de cada gol.

Dashboard: stream de eventos a cada segundo, histórico da execução selecionada, cenário selecionável e linhas por adversário. Detecta perda de conexão, interrupção de processo e heartbeat atrasado. O servidor local é somente leitura e não inicia POCs.

## Comparação controlada após 1.000 iterações

`src/reward_sweep.py` executa seis treinos de self-play: aproximação 0,60 / 0,15 / 0,05, seeds 0 e 1, 300 iterações × 256 ambientes × 64 decisões por treino (4.915.200 amostras). Todos partem do mesmo checkpoint it650, mantêm gol ±25 e progresso 0,08 e reiniciam o critic. A ordem dos pesos é invertida na segunda seed. O runtime de simulação usa quatro threads e PyTorch duas para compartilhar CPU com a sala real.

Cada execução mantém a mesma avaliação por adversário e grava inspeção de comportamento do checkpoint final. Comparar endpoints e cenários aleatórios; registrar melhor checkpoint separadamente. Os seis treinos são uma triagem, não prova de convergência robusta nem extrapolação para 20 mil iterações. O dashboard acompanha a execução ativa; os históricos anteriores permanecem em suas pastas.

A inspeção registra distância da bola, intenção de chute durante proximidade, alinhamento aproximado com o gol, posição defensiva e períodos com bola parada. Essas métricas não identificam com certeza chutes efetivos nem autoria de gols. As parcelas absolutas de recompensa passam a ser gravadas para evitar confundir cancelamento do saldo de gols com ausência de sinal de gol.

# Haxball RL

Agentes de reinforcement learning para Haxball, treinados com PPO e self-play sobre HaxballGym. A prioridade atual é consolidar o 1v1 em `futsal-classic`, com avaliação reproduzível, antes de experimentar equipes e fine-tuning.

## Uso

Python >=3.12, uv e PyTorch CPU conforme `pyproject.toml` e `uv.lock`:

```bash
uv sync
uv run src/train.py --stadium maps/futsal_1v1.hbs --red 1 --blue 1 --envs 512 --iters 1500 --out models/run_1v1_seed0 --seed 0
```

Use uma pasta por execução. O treinamento grava pesos e metadados, mas ainda não salva a configuração completa, estado do otimizador ou pool de adversários. `--warm-start` carrega pesos, zerando a cabeça de valor por padrão; `--keep-critic` preserva essa cabeça.

Os comandos abaixo leem os modelos da pasta padrão `models/`:

```bash
uv run src/eval.py --benchmark --stadium futsal-classic
uv run src/select.py --stadium futsal-classic
```

`select.py` promove o vencedor para `models/model.pt` e atualiza `meta.json`. Os scripts antigos usam gols agregados. `src/repair_bot.py` oferece uma avaliação mais completa com seeds, cenários variados e resultados por episódio.

## Experimento de correção 1v1

```bash
uv run src/repair_bot.py --out experiments/nova_correcao --iters 100 --seeds 0 1 2
uv run python -m unittest discover -s tests -v
```

O experimento salva os pesos em pasta separada. Usa mapa com paredes corrigidas, recompensas por deslocamento e chute rearmado.

## Sala real

Execute a partir da raiz do repositório:

```bash
uv run headless-bot/export_policy.py models/model.pt
cd headless-bot
npm install
HEADLESS_TOKEN="<token>" node bot.js
```

O exportador atual aceita observações de 16 dimensões e uma rede de duas camadas, para 1v1. A transferência para a sala precisa ser validada em partidas reais; equivalência de física, observações e latência não é certificada por este repositório. Veja `headless-bot/README.md`.

## Organização

- `src/model.py`, `src/bot.py`: política e bots de referência.
- `src/train.py`: PPO, recompensas e self-play.
- `src/eval.py`, `src/select.py`: benchmark e torneio de checkpoints.
- `src/replay.py`: utilitários de replay.
- `maps/`: estádios; `models/`: pesos e metadados.
- Scripts `inspect_*` e `test_*` na raiz: diagnósticos e experimentos, sem uma suíte unificada.

`AGENTS.md` descreve a arquitetura implementada; `PROTOCOL.md`, os parâmetros e recompensas; `TODO.md`, as próximas etapas; `CONTEXT.md`, o histórico e as limitações dos resultados disponíveis.

## Self-play monitorado

```bash
uv run src/train.py --envs 512 --iters 1000 --threads 2 --warm-start models/model.pt --keep-critic --out runs/minha_execucao --save-every 50 --eval-every 50
uv run live_stats_server.py --port 8085
```

O dashboard em `http://127.0.0.1:8085` lê a execução apontada por `runs/active.json` (`{"path":"/caminho/absoluto/da/execucao"}`). O treinador grava estado atômico, registros por iteração e avaliações por adversário. Há uma avaliação inicial na iteração zero; durante avaliações o treino pausa e o painel mostra essa fase. A velocidade de treino exclui avaliações; a estimativa restante é só do treino.

Os adversários são Chase com/sem ruído, atacante posicional, goleiro e a política inicial congelada. Cenários e seeds de avaliação permanecem fixos. O modelo principal é preservado: pesos finais e melhor checkpoint por pontuação equilibrada ficam na pasta da execução. A pontuação conta vitória como 1, empate como 0,5 e derrota como 0; não confundir com proporção dos gols. Kickoffs determinísticos continuam sendo trajetórias correlacionadas, e autoria de gols contra não é classificada.

"""Two bots over a HaxballGym env.

- `ChaseBot`  — scripted baseline: run at the ball, kick when close. It reads the raw
  game **state** (`ball_pos` / `player_pos`), so there are no magic observation indices.
- `NeuralBot` — loads the trained policy (`models/model.pt` + `meta.json`).

`ChaseBot.act(state, players)` takes a `GameState` and the player columns to control.
`NeuralBot.act(obs)` takes an egocentric observation block (what the policy is trained on).
"""

from __future__ import annotations

import json
from pathlib import Path

import numpy as np


class ChaseBot:
    """Heuristic: steer toward the ball (with a little angular jiggle so it isn't on rails),
    kick when within `kick_dist`. Reads positions from the state — map/obs agnostic."""

    def __init__(self, kick_dist: float = 34.0, jiggle: float = 0.25, seed: int | None = None):
        self.kick_dist = kick_dist
        self.jiggle = jiggle
        self.rng = np.random.default_rng(seed)

    def act(self, state, players, n_red: int = 1) -> np.ndarray:
        """state: GameState; players: index array of columns to control -> bins (N, K, 3)."""
        ball = state.ball_pos[:, None, :]  # (N, 1, 2)
        pos = state.player_pos[:, players, :]  # (N, K, 2)
        d = ball - pos
        dist = np.hypot(d[..., 0], d[..., 1])
        ang = np.arctan2(d[..., 1], d[..., 0]) + self.rng.normal(0.0, self.jiggle, dist.shape)
        dx, dy = np.cos(ang), np.sin(ang)
        # In HaxballGym, actions are in policy frame (un-mirrored by env.step for blue).
        # For Blue players, forward (towards ball/goal on the left) is bin 2 (+1 in policy frame).
        p_arr = np.asarray(players)
        is_blue = p_arr >= n_red
        if np.any(is_blue):
            dx[..., is_blue] = -dx[..., is_blue]
        bx = np.where(dx > 0.33, 2, np.where(dx < -0.33, 0, 1))
        by = np.where(dy > 0.33, 2, np.where(dy < -0.33, 0, 1))
        kick = (dist < self.kick_dist).astype(np.int64)
        return np.stack([bx, by, kick], -1).astype(np.int64)


class NeuralBot:
    """The trained WazBot. Greedy (deterministic) by default; `greedy=False` samples."""

    def __init__(self, model_dir: str | Path | None = None, greedy: bool = True):
        import torch  # local import so ChaseBot stays torch-free

        from model import Policy

        model_dir = Path(model_dir) if model_dir else Path(__file__).resolve().parent.parent / "models"
        meta = json.loads((model_dir / "meta.json").read_text())
        self.greedy = greedy
        self._torch = torch
        self.model = Policy(meta["obs_dim"], meta["n_acts"], meta["hidden"], meta["depth"])
        self.model.load_state_dict(torch.load(model_dir / "model.pt", map_location="cpu"))
        self.model.eval()

    def act(self, obs: np.ndarray) -> np.ndarray:
        """obs (..., obs_dim) -> bins (M, len(n_acts))."""
        o = self._torch.as_tensor(obs.reshape(-1, obs.shape[-1]), dtype=self._torch.float32)
        return self.model.act(o, greedy=self.greedy).numpy().astype(np.int64)


class RandomBot:
    """Samples uniform random actions across movement and kick heads."""

    def __init__(self, seed: int | None = None):
        self.rng = np.random.default_rng(seed)

    def act(self, obs: np.ndarray) -> np.ndarray:
        shape = obs.shape[:-1] if obs.ndim > 1 else (1,)
        m_x = self.rng.integers(0, 3, size=(*shape, 1))
        m_y = self.rng.integers(0, 3, size=(*shape, 1))
        kick = self.rng.integers(0, 2, size=(*shape, 1))
        return np.concatenate([m_x, m_y, kick], axis=-1).astype(np.int64)



class PositionBot:
    """Position before kicking; avoid kicking toward the bot's own goal.

    defender=True keeps a keeper near the own goal; otherwise approach from behind
    the ball relative to the finite opponent goal mouth. Scripted evaluation only.
    """
    def __init__(self, defender=False):
        self.defender = defender

    def act(self, state, players, n_red=1):
        players = np.asarray(players)
        ball = state.ball_pos[:, None, :]
        pos = state.player_pos[:, players]
        goal = state.goal_center(attacked=True)[:, players]
        toward = goal-ball
        toward /= np.maximum(np.linalg.norm(toward, axis=-1, keepdims=True), 1e-9)
        target = ball-toward*27.
        if self.defender:
            own = state.goal_center(attacked=False)[:, players]
            target = own.copy()
            target[..., 0] *= .88
            target[..., 1] = np.clip(ball[..., 1], -55., 55.)
        move = target-pos
        delta = ball-pos
        distance = np.linalg.norm(delta, axis=-1)
        aligned = np.sum(delta*toward,axis=-1)>distance*.5
        kick = ((distance<24.8)&aligned).astype(np.int64)
        move[...,0] *= np.where(players>=n_red,-1,1)
        bx=np.where(move[...,0]>3,2,np.where(move[...,0]<-3,0,1))
        by=np.where(move[...,1]>3,2,np.where(move[...,1]<-3,0,1))
        return np.stack([bx,by,kick],axis=-1).astype(np.int64)

"""Validated 1v1 map, motion-based shaping and live-room kick semantics."""
from pathlib import Path
import json
import numpy as np
from haxballgym import DiscreteAction
from haxballgym.reward import RewardFunction

STADIUM = str(Path(__file__).resolve().parent.parent / 'maps' / 'futsal_1v1.hbs')


def motion_scale(stadium: str | None, tick_skip: int) -> float:
    """Maximum free player displacement per decision, using explicit map physics."""
    from haxballgym.stadium import stadium_text
    data = json.loads(stadium_text(stadium or 'classic'))
    physics = data.get('playerPhysics', {})
    acceleration = float(physics.get('acceleration', .1))
    damping = float(physics.get('damping', .96))
    if not 0 < damping < 1 or acceleration <= 0:
        raise ValueError('Motion shaping requires positive acceleration and damping in (0,1).')
    return acceleration * damping / (1-damping) * tick_skip


class MotionPlayerToBall(RewardFunction):
    """Signed actual player displacement toward the previous ball position.

    A blocked player with nonzero reported velocity receives zero reward. The ball's
    own motion does not penalize a good shot by increasing player-ball distance.
    """
    def __init__(self, scale):
        self.scale = scale

    def get_rewards(self, state, prev, terminated, truncated):
        if prev is None:
            return np.zeros(state.player_pos.shape[:2], dtype=np.float32)
        direction = prev.ball_pos[:, None, :] - prev.player_pos
        direction /= np.maximum(np.linalg.norm(direction, axis=-1, keepdims=True), 1e-9)
        displacement = state.player_pos - prev.player_pos
        return (np.sum(displacement * direction, axis=-1) / self.scale).astype(np.float32)


class MotionBallToGoal(RewardFunction):
    """Signed decrease in distance to the opponent's finite goal mouth.

    Return motion cancels previous progress on an undiscounted closed trajectory.
    Measures movement, not reported instantaneous velocity or last toucher.
    """
    def __init__(self, scale):
        self.scale = scale

    @staticmethod
    def distance(state):
        p0, p1 = state.goal_line(attacked=True)
        segment = p1 - p0
        ball = state.ball_pos[:, None, :]
        t = np.sum((ball-p0)*segment, axis=-1, keepdims=True)
        t /= np.maximum(np.sum(segment*segment, axis=-1, keepdims=True), 1e-9)
        target = p0 + np.clip(t, 0, 1)*segment
        return np.linalg.norm(ball-target, axis=-1)

    def get_rewards(self, state, prev, terminated, truncated):
        if prev is None:
            return np.zeros(state.player_pos.shape[:2], dtype=np.float32)
        return ((self.distance(prev)-self.distance(state))/self.scale).astype(np.float32)


class RepeatKickAction(DiscreteAction):
    """Policy still chooses release/press; press re-arms kicks inside the tick window.

    The live bot already releases/represses each tick. Engine input 2 implements that
    same behavior while keeping two policy bins and compatibility with old weights.
    """
    def __init__(self):
        super().__init__(kick_values=2)

    def parse_actions(self, actions):
        parsed = super().parse_actions(actions)
        parsed[..., 2] *= 2
        return parsed

            obs = env.obs_builder.build_obs(env.prev_state)
            capture = []
            original_reward = env.reward_fn

            class CaptureState:
                def get_rewards(self, state, previous, terminated, truncated):
                    capture.append(state)
                    return original_reward.get_rewards(state, previous, terminated, truncated)

            env.reward_fn = CaptureState()
            done = np.zeros(envs, dtype=bool)
            first_contact = np.full(envs, -1, dtype=int)
            near_steps = np.zeros(envs, dtype=int)
            near_presses = np.zeros(envs, dtype=int)
            aimed_impulses = np.zeros(envs, dtype=int)
            goals_for = np.zeros(envs, dtype=int)
            goals_against = np.zeros(envs, dtype=int)
            ball_goal_delta = np.zeros(envs, dtype=float)
            decisions = np.zeros(envs, dtype=int)
            for step in range(max_steps):
                previous = env.prev_state
                action = model.act(torch.as_tensor(obs[:, side], dtype=torch.float32), greedy=True).numpy()
                action[done] = [1, 1, 0]
                delta = previous.ball_pos - previous.player_pos[:, side]
                distance = np.linalg.norm(delta, axis=-1)
                near = (distance < 24.8) & ~done
                new_contact = near & (first_contact < 0)
                first_contact[new_contact] = step
                near_steps += near.astype(int)
                pressed = (action[:, 2] == 1) & near
                near_presses += pressed.astype(int)
                opponent_action = np.zeros((envs, 3), dtype=np.int64)
                opponent_action[:, 0:2] = 1
                actions = np.empty((envs, 2, 3), dtype=np.int64)
                actions[:, side] = action
                actions[:, 1-side] = opponent_action
                obs, _, terminated, truncated = env.step(actions)
                post = capture.pop()
                active = ~done
                goals_for += ((post.scored == (BLUE if side == 0 else RED)) & active).astype(int)
                goals_against += ((post.scored == (RED if side == 0 else BLUE)) & active).astype(int)
                to_goal = previous.goal_center(attacked=True)[:, side] - previous.ball_pos
                to_goal /= np.maximum(np.linalg.norm(to_goal, axis=-1, keepdims=True), 1e-9)
                impulse = post.ball_vel - previous.ball_vel
                toward = np.sum(impulse * to_goal, axis=-1) > .2
                aimed_impulses += (pressed & toward).astype(int)
                ball_goal_delta += (np.linalg.norm(previous.goal_center(attacked=True)[:, side] - previous.ball_pos, axis=-1)
                    - np.linalg.norm(post.goal_center(attacked=True)[:, side] - post.ball_pos, axis=-1)) * active
                newly_done = (terminated | truncated) & active
                decisions[active] += 1
                done |= newly_done
                if done.all():
                    break
            rows.append({
                "side": side,
                "wall": "bottom" if wall > 0 else "top",
                "start_ball": [float(ball[0, 0]), float(ball[0, 1])],
                "start_player": [float(players[0, side, 0]), float(players[0, side, 1])],
                "episodes": int(envs),
                "completed": int(done.sum()),
                "goals_for": int(goals_for.sum()),
                "goals_against": int(goals_against.sum()),
                "contact_fraction": float((first_contact >= 0).mean()),
                "mean_first_contact_decisions": float(first_contact[first_contact >= 0].mean()) if (first_contact >= 0).any() else None,
                "near_contact_decisions": int(near_steps.sum()),
                "near_contact_presses": int(near_presses.sum()),
                "press_with_goalward_impulse": int(aimed_impulses.sum()),
                "mean_center_goal_distance_reduction": float(ball_goal_delta.sum() / max(1, decisions.sum())),
                "mean_episode_decisions": float(decisions.mean()),
            })
    return {"checkpoint": str(checkpoint), "envs_per_case": envs, "max_steps": max_steps,
            "opponent": "stationary (no movement, no kick)", "stadium": STADIUM, "rows": rows,
            "limitation": "Fixed scripted states test this corner pattern only; a goalward impulse is not proof that the ball entered the goal."}

"""The policy network — a small actor-critic MLP.

Three categorical heads (dx, dy, kick) over a shared trunk, plus a value head. The head
*sizes* come from the env's action space (`env.action_space` -> `(3, 3, kick_n)`), so
nothing about the action layout is hardcoded — but the weight names (`trunk.0/2`,
`head_x/y/k`) and depth-2 trunk match HaxballGym's `headless-bot` exporter, so a trained
`model.pt` deploys to a real room with no extra work. `meta.json` records the shapes.
"""

from __future__ import annotations

from collections.abc import Sequence

import torch
import torch.nn as nn
from torch.distributions import Categorical


class Policy(nn.Module):
    def __init__(
        self,
        obs_dim: int,
        n_acts: Sequence[int] = (3, 3, 2),
        hidden: int = 256,
        depth: int = 2,
    ):
        super().__init__()
        self.n_acts = tuple(n_acts)
        nx, ny, nk = self.n_acts
        layers, d = [], obs_dim
        for _ in range(depth):
            layers += [nn.Linear(d, hidden), nn.Tanh()]
            d = hidden
        self.trunk = nn.Sequential(*layers)
        self.head_x = nn.Linear(hidden, nx)  # dx bin
        self.head_y = nn.Linear(hidden, ny)  # dy bin
        self.head_k = nn.Linear(hidden, nk)  # kick: 0/1 (release/hold) or 0/1/2 (+rocket)
        self.value = nn.Linear(hidden, 1)

    def _logits(self, obs):
        h = self.trunk(obs)
        return (self.head_x(h), self.head_y(h), self.head_k(h)), self.value(h).squeeze(-1)

    def act_train(self, obs):
        """Sample actions + return (actions, summed log-prob, value) for a rollout step."""
        logits, v = self._logits(obs)
        dists = [Categorical(logits=lg) for lg in logits]
        a = torch.stack([d.sample() for d in dists], -1)
        logp = sum(d.log_prob(a[:, i]) for i, d in enumerate(dists))
        return a, logp, v

    def evaluate(self, obs, acts):
        """Log-prob + entropy of given actions under the current policy (PPO update)."""
        logits, v = self._logits(obs)
        dists = [Categorical(logits=lg) for lg in logits]
        logp = sum(d.log_prob(acts[:, i]) for i, d in enumerate(dists))
        ent = sum(d.entropy() for d in dists)
        return logp, ent, v

    @torch.no_grad()
    def act(self, obs, greedy: bool = False):
        """obs (M, obs_dim) float tensor -> action bins (M, 3) long tensor."""
        logits, _ = self._logits(obs)
        if greedy:
            return torch.stack([lg.argmax(-1) for lg in logits], -1)
        return torch.stack([Categorical(logits=lg).sample() for lg in logits], -1)

            # Capture terminal state inside reward callback, before autoreset.
            captured = []
            original = env.reward_fn
            class Capture:
                def get_rewards(self, st, prev, term, trunc):
                    captured.append(st)
                    return original.get_rewards(st, prev, term, trunc)
            env.reward_fn = Capture()
            _, _, term, trunc = env.step(act)
            env.reward_fn = original
            st = captured[0]
            progress += float(original.terms[1][0].get_rewards(st, previous, term, trunc)[0, 0]) * original.terms[1][1]
            vx.append(float(st.ball_vel[0, 0]))
            goals += int(st.scored[0] == BLUE)
            if term[0] or trunc[0]:
                break
        shots[name] = dict(progress_sum=progress, red_goals=goals, min_vx=min(vx), max_vx=max(vx), decisions=len(vx))
    assert shots["open"]["max_vx"] > 0
    assert shots["blocked"]["min_vx"] < 0
    assert shots["open"]["progress_sum"] > shots["blocked"]["progress_sum"]
    return dict(player_max_speed=float(state.player_max_speed), forward=forward, backward=backward, undiscounted_roundtrip=forward[0]+backward[0],
                scored=value(scored=BLUE), conceded=value(scored=RED), engine_shots=shots)


@torch.no_grad()
def evaluate(model, seeds, n, steps, stadium=STADIUM):
    rows = []
    for seed in seeds:
        for opponent in ("chase", "chase_no_noise", "random"):
            for side in (0, 1):
                seed_all(seed)
                env = create_eval_env(n, 1, 1, stadium, 8)
                obs = env.reset()
                bot = RandomBot(seed) if opponent == "random" else ChaseBot(seed=seed, jiggle=0. if opponent == "chase_no_noise" else .25)
                gf = ga = 0
                for _ in range(steps):
                    actions = np.empty((n, 2, 3), dtype=np.int64)
                    actions[:, side] = model.act(torch.as_tensor(obs[:, side], dtype=torch.float32), greedy=True).numpy()
                    other = 1-side
                    actions[:, other] = (bot.act(obs[:, other]) if opponent == "random" else bot.act(env.prev_state, [other])).reshape(n, 3)
                    obs, _, _, _ = env.step(actions)
                    scored = env.prev_state.scored
                    gf += int((scored == (BLUE if side == 0 else RED)).sum())
                    ga += int((scored == (RED if side == 0 else BLUE)).sum())
                rows.append(dict(seed=seed, opponent=opponent, side=side, gf=gf, ga=ga, net=gf-ga))
    return rows


def train(table, seed, args, initial):
    seed_all(seed)
    env = create_training_env(args.envs, 1, 1, args.stadium, 8, seed=seed, table=table)
    env.reward_fn = build_reward(table, args.stadium, 8)
    model = Policy(env.obs_dim, env.action_space)
    model.load_state_dict(initial)
    if getattr(args, "reset_value", False):
        torch.nn.init.zeros_(model.value.weight)
        torch.nn.init.zeros_(model.value.bias)
    opt = torch.optim.Adam(model.parameters(), lr=LR)
    chase = ChaseBot(seed=seed)
    obs = env.reset()
    gamma = math.exp(math.log(.5) / (7.5 * HALF_LIFE_S))
    totals = {type(fn).__name__: 0. for fn, _ in env.reward_fn.terms}
    # Capture contributions before automatic episode resets.
    original = env.reward_fn
    class Meter:
        def get_rewards(self, st, prev, term, trunc):
            result = np.zeros((args.envs, 2), dtype=np.float32)
            for fn, weight in original.terms:
                part = fn.get_rewards(st, prev, term, trunc) * weight
                totals[type(fn).__name__] += float(part[:, 0].sum())
                result += part
            return result
    env.reward_fn = Meter()
    for it in range(args.iters):
        frac = it / max(1, args.iters-1)
        for group in opt.param_groups:
            group['lr'] = LR*(1-frac) + LR/3*frac
        ent_coef = ENT0*(1-frac) + ENT1*frac
        so, sa, sl, sv, sr, sd = [], [], [], [], [], []
        for _ in range(T):
            o = torch.as_tensor(obs[:, 0], dtype=torch.float32)
            with torch.no_grad():
                a, logp, v = model.act_train(o)
            actions = np.empty((args.envs, 2, 3), dtype=np.int64)
            actions[:, 0] = a.numpy()
            actions[:, 1] = chase.act(env.prev_state, [1]).reshape(args.envs, 3)
            obs, rew, term, trunc = env.step(actions)
            so.append(o); sa.append(a); sl.append(logp); sv.append(v)
            sr.append(torch.as_tensor(rew[:, 0])); sd.append(torch.as_tensor(term | trunc))
        so, sa, sl, sv, sr, sd = map(torch.stack, (so, sa, sl, sv, sr, sd))
        with torch.no_grad():
            nextv = model._logits(torch.as_tensor(obs[:, 0], dtype=torch.float32))[1]
        adv = torch.zeros_like(sr); gae = torch.zeros(args.envs)
        for t in reversed(range(T)):
            mask = (~sd[t]).float()
            delta = sr[t] + gamma*nextv*mask - sv[t]
            gae = delta + gamma*LAM*mask*gae
            adv[t] = gae; nextv = sv[t]
        ret = (adv+sv).flatten()
        adv = adv.flatten(); adv = (adv-adv.mean())/(adv.std()+1e-8)
        bo, ba, bl = so.reshape(-1, env.obs_dim), sa.reshape(-1, 3), sl.flatten()
        for _ in range(EPOCHS):
            for mi in torch.randperm(T*args.envs).chunk(N_MB):
                logp, entropy, val = model.evaluate(bo[mi], ba[mi])
                ratio = (logp-bl[mi]).exp()
                loss = -torch.minimum(ratio*adv[mi], ratio.clamp(1-CLIP, 1+CLIP)*adv[mi]).mean()
                loss += VF_COEF*.5*(val-ret[mi]).square().mean() - ent_coef*entropy.mean()
                opt.zero_grad(); loss.backward()
                torch.nn.utils.clip_grad_norm_(model.parameters(), MAX_GRAD); opt.step()
        if (it+1) % 10 == 0:
            print(f'{table} seed={seed} iteration={it+1}/{args.iters}', flush=True)
    torch.save(model.state_dict(), args.out / f'{table}_seed{seed}.pt')
    return dict(table=table, seed=seed, contributions=totals,
                evaluation=evaluate(model, args.eval_seeds, args.eval_envs, args.eval_steps, args.stadium))

def selection_score(rows):
    """Equal weight per held-out condition, using the deployment (greedy) mode."""
    scores=[]
    for row in rows:
        if row['opponent']=='random' or not row['greedy']:
            continue
        completed=row['wins']+row['draws']+row['losses']
        if completed:
            scores.append((row['wins']+.5*row['draws'])/completed)
    return float(np.mean(scores)) if scores else 0.

"""Dump a self-play game as a watchable `.hbr2` so you can SEE how training is going.

`train.py --replay-every N` calls this every N iters. We play one game in the Rust core and
record each player's per-decision input mask; then (if Node + HaxballGym's `record_replay.js`
are available) we replay those inputs in an offline node-haxball sandbox to write a real `.hbr2`
loadable in any Haxball replay viewer. Without Node we still write the `.trace.json` and tell you
how to convert it. The `.hbr2` step needs Node because node-haxball is the actual game recorder.
"""

from __future__ import annotations

import json
import subprocess
from pathlib import Path

import numpy as np
import torch

from haxballgym import DefaultObs, KickoffMutator, TransitionEngine, stadium_text


def bins_to_mask(dx: int, dy: int, kick: int) -> int:
    """World-frame action bins {-1,0,1} -> Haxball 5-bit input mask (UP1 DOWN2 LEFT4 RIGHT8 KICK16)."""
    m = 0
    m |= 8 if dx > 0 else 4 if dx < 0 else 0  # RIGHT / LEFT
    m |= 1 if dy > 0 else 2 if dy < 0 else 0  # UP / DOWN
    m |= 16 if kick else 0
    return m


@torch.no_grad()
def dump_trace(model, *, stadium, n_red, n_blue, tick_skip, n_decisions=300, device="cpu"):
    """Play one self-play game (model controls every player) and return the input-trace dict."""
    P = n_red + n_blue
    stad = stadium or "classic"
    eng = TransitionEngine(1, n_red, n_blue, stadium=stadium, tick_skip=tick_skip)
    obs_builder = DefaultObs(pos_coef="auto") if stadium else DefaultObs()
    state = KickoffMutator().reset_all(eng)
    obs_builder.reset(state)
    spawns = np.asarray(state.player_pos)[0].tolist()  # record_replay.js maps haxball players by spawn
    decisions = []
    for _ in range(n_decisions):
        o = np.asarray(obs_builder.build_obs(state))
        flat = torch.as_tensor(o.reshape(-1, o.shape[-1]), dtype=torch.float32, device=device)
        bins = model.act(flat).cpu().numpy().reshape(P, 3)
        masks, eng_acts = [], np.zeros((1, P, 3), np.int64)
        for p in range(P):
            dx, dy, kick = int(bins[p, 0]) - 1, int(bins[p, 1]) - 1, int(bins[p, 2])
            wdx = dx if p < n_red else -dx  # blue un-mirrors dx (matches Env._mirror_x / training)
            eng_acts[0, p] = (wdx, dy, kick)
            masks.append(bins_to_mask(wdx, dy, kick))
        decisions.append(masks)
        state = eng.step(eng_acts)
    return {
        "hbs": stadium_text(stad),
        "n_red": n_red,
        "n_blue": n_blue,
        "tick_skip": tick_skip,
        "spawns": spawns,
        "decisions": decisions,
    }


def dump_replay(
    model,
    out_hbr2,
    *,
    stadium,
    n_red,
    n_blue,
    tick_skip,
    record_js,
    n_decisions=300,
    device="cpu",
    background=False,
):
    """Write `out_hbr2` (or just the trace if no Node/record_replay.js). Best-effort: never raises.
    `background=True` launches the Node recorder fire-and-forget (don't block the training loop)."""
    out_hbr2 = Path(out_hbr2)
    trace_path = out_hbr2.with_suffix(".trace.json")
    trace_path.write_text(
        json.dumps(
            dump_trace(
                model,
                stadium=stadium,
                n_red=n_red,
                n_blue=n_blue,
                tick_skip=tick_skip,
                n_decisions=n_decisions,
                device=device,
            )
        )
    )
    if not record_js or not Path(record_js).exists():
        return False, f"trace at {trace_path} (set --record-js <path/to/record_replay.js> for .hbr2)"
    cmd = ["node", str(record_js), str(trace_path), str(out_hbr2)]
    try:
        if background:  # fire-and-forget: node reads the trace async; don't stall training
            subprocess.Popen(cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
            return True, "(recording in background)"
        r = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
        if r.returncode != 0:
            return False, (r.stderr or r.stdout)[-300:]
        trace_path.unlink()
        return True, str(out_hbr2)
    except Exception as e:  # noqa: BLE001
        return False, str(e)

def load(path: Path):
    """Rebuild a Policy from a checkpoint, inferring the architecture from the weights."""
    sd = torch.load(path, map_location="cpu")
    obs_dim = sd["trunk.0.weight"].shape[1]
    hidden = sd["trunk.0.weight"].shape[0]
    depth = sum(1 for k in sd if k.startswith("trunk.") and k.endswith(".weight"))
    nk = sd["head_k.weight"].shape[0]
    m = Policy(obs_dim, (3, 3, nk), hidden, depth)
    m.load_state_dict(sd)
    m.eval()
    return m


@torch.no_grad()
def h2h(a, b, stadium: str | None = None, n_envs: int = 128, steps: int = 350):
    """Goals (a, b) with `a`=red, `b`=blue over one set of games."""
    env = create_eval_env(n_envs, 1, 1, stadium or STADIUM, 8)
    obs = env.reset()
    od = obs.shape[-1]
    ag = bg = 0
    for _ in range(steps):
        ra = a.act(torch.as_tensor(obs[:, 0:1].reshape(-1, od), dtype=torch.float32)).numpy()
        rb = b.act(torch.as_tensor(obs[:, 1:2].reshape(-1, od), dtype=torch.float32)).numpy()
        obs, rew, term, trunc = env.step(np.stack([ra, rb], axis=1).reshape(n_envs, 2, 3))
        sc = env.prev_state.scored
        ag += int((sc == BLUE).sum())  # blue conceded -> a (red) scored
        bg += int((sc == RED).sum())
    return ag, bg

def atomic_json(path, value):
    path = Path(path)
    temporary = path.with_name(path.name + '.tmp')
    temporary.write_text(json.dumps(value, allow_nan=False))
    os.replace(temporary, path)


class Telemetry:
    def __init__(self, out, config):
        self.out = Path(out)
        self.start = time.monotonic()
        self.state = dict(schema_version=1, pid=os.getpid(), status='running', phase='starting',
                          iteration=0, completed_iterations=0, rollout_step=0, config=config)
        atomic_json(self.out/'config.json', config)
        self.update()

    def update(self, **fields):
        self.state.update(fields)
        self.state['updated_at'] = datetime.now(timezone.utc).isoformat()
        self.state['elapsed_s'] = time.monotonic()-self.start
        atomic_json(self.out/'live.json', self.state)

    def append(self, filename, record):
        record = dict(record, timestamp=datetime.now(timezone.utc).isoformat())
        with (self.out/filename).open('a') as handle:
            handle.write(json.dumps(record, allow_nan=False)+'\n')


class RewardMeter:
    def __init__(self, reward):
        self.reward = reward
        self.clear()

    def clear(self):
        self.sums = {type(fn).__name__: 0. for fn, _ in self.reward.terms}
        self.absolute_sums = dict.fromkeys(self.sums, 0.)
        self.gf = self.ga = self.finished = self.stationary = self.transitions = 0

    def reset(self, state):
        self.reward.reset(state)

    def get_rewards(self, state, prev, terminated, truncated):
        from haxballgym import BLUE, RED
        result = np.zeros(state.player_pos.shape[:2], dtype=np.float32)
        for fn, weight in self.reward.terms:
            part = fn.get_rewards(state, prev, terminated, truncated)*weight
            result += part
            self.sums[type(fn).__name__] += float(part[:, 0].sum())
            self.absolute_sums[type(fn).__name__] += float(np.abs(part[:,0]).sum())
        self.gf += int((state.scored==BLUE).sum())
        self.ga += int((state.scored==RED).sum())
        self.finished += int((terminated|truncated).sum())
        if prev is not None:
            self.stationary += int((np.linalg.norm(state.ball_pos-prev.ball_pos,axis=-1)<.01).sum())
        self.transitions += state.n_envs
        return result

class DeltaBreakawayReward(RewardFunction):
    """Rewards overcoming/dribbling past the defender:
    Gives positive reward ONLY at the moment when the ball-carrier gains a goal-side
    advantage over the defender (i.e. breaks past the defender line towards goal)."""

    def __init__(self, scale: float = 250.0, mult: float = 3.0):
        self.scale = scale
        self.mult = mult

    def _phi(self, state):
        d_ball = np.linalg.norm(state.ball_pos[:, None, :] - state.player_pos, axis=-1)
        has_ball = d_ball == d_ball.min(axis=-1, keepdims=True)
        attacked = state.goal_center(attacked=True)
        my_d = np.linalg.norm(state.player_pos - attacked, axis=-1)
        diff = state.player_pos[:, None, :, :] - attacked[:, :, None, :]
        d_o = np.linalg.norm(diff, axis=-1)
        opp = state.team[:, None, :] != state.team[:, :, None]
        def_d = np.where(opp, d_o, np.inf).min(axis=-1)
        ahead = np.minimum(np.maximum(def_d - my_d, 0.0) / self.scale, 1.0)
        return (has_ball * ahead).astype(np.float32)

    def get_rewards(self, state, prev, terminated, truncated):
        curr_phi = self._phi(state)
        prev_phi = self._phi(prev) if prev is not None else curr_phi
        delta = np.maximum(curr_phi - prev_phi, 0.0)
        return (delta * self.mult).astype(np.float32)


class ShotVelocityToGoal(RewardFunction):
    """Event-style reward: credits ball speed toward opponent goal on touches and kicks.
    Robust to discrete tick-skips (34px range evaluated across previous and current tick)."""

    def __init__(self, contact_dist: float = 34.0, scale: float = 2.0):
        self.contact_dist = contact_dist
        self.vbg = VelocityBallToGoal(attacked=True)
        self.scale = scale

    def get_rewards(self, state, prev, terminated, truncated):
        curr_d = np.linalg.norm(state.ball_pos[:, None, :] - state.player_pos, axis=-1)
        touch_curr = curr_d < self.contact_dist
        touch_prev = False
        if prev is not None:
            prev_d = np.linalg.norm(prev.ball_pos[:, None, :] - prev.player_pos, axis=-1)
            touch_prev = prev_d < self.contact_dist
        touching = touch_curr | touch_prev
        v = self.vbg.get_rewards(state, prev, terminated, truncated)
        return (np.maximum(v, 0.0) * touching * self.scale).astype(np.float32)


class TangentialGoalShotReward(RewardFunction):
    """Rewards accelerating the ball towards the opponent's goal mouth (between the posts),
    NOT into corners/walls."""
    def __init__(self, post_y_limit: float = 65.0, scale: float = 3.0):
        self.post_y_limit = post_y_limit
        self.scale = scale

    def get_rewards(self, state, prev, terminated, truncated):
        if prev is None:
            return np.zeros((state.ball_pos.shape[0], state.player_pos.shape[1]), dtype=np.float32)
        target = state.goal_center(attacked=True)
        goal_x = target[:, :, 0]
        ball_disp = state.ball_pos - prev.ball_pos
        dx = ball_disp[:, 0:1]
        dy = ball_disp[:, 1:2]
        is_toward_goal = np.sign(dx) == np.sign(goal_x)
        dist_x = np.maximum(np.abs(goal_x - state.ball_pos[:, 0:1]), 1.0)
        proj_y = state.ball_pos[:, 1:2] + dy * (dist_x / (np.abs(dx) + 1e-4))
        in_mouth = (np.abs(proj_y) <= self.post_y_limit) | (np.abs(state.ball_pos[:, 1:2]) <= self.post_y_limit)
        speed = np.linalg.norm(ball_disp, axis=-1, keepdims=True)
        d_ball = np.linalg.norm(state.player_pos - state.ball_pos[:, None, :], axis=-1)
        touch = d_ball < 36.0
        shot_val = is_toward_goal * in_mouth * speed * touch * self.scale
        return shot_val.astype(np.float32)


class PenaltyTackleLostReward(RewardFunction):
    """Discrete penalty when player had breakaway advantage but lost ball directly to defender."""
    def __init__(self, penalty: float = -0.5):
        self.penalty = penalty
        self.breakaway = DeltaBreakawayReward()

    def get_rewards(self, state, prev, terminated, truncated):
        if prev is None:
            return np.zeros((state.ball_pos.shape[0], state.player_pos.shape[1]), dtype=np.float32)
        prev_phi = self.breakaway._phi(prev)
        d_ball = np.linalg.norm(state.ball_pos[:, None, :] - state.player_pos, axis=-1)
        has_ball = d_ball == d_ball.min(axis=-1, keepdims=True)
        had_adv = prev_phi > 0.2
        lost = ~has_ball
        opp_contact = d_ball.min(axis=-1, keepdims=True) < 34.0
        tackle = had_adv & lost & opp_contact
        return (tackle * self.penalty).astype(np.float32)


def build_reward(table="corrected", stadium=STADIUM, tick_skip=8, approach_weight=0.15):
    """Signed shaping; retain the previous table for controlled POC comparisons."""
    if table == "corrected":
        scale = motion_scale(stadium, tick_skip)
        return CombinedReward(
            (MotionPlayerToBall(scale), approach_weight),
            (MotionBallToGoal(scale), 0.08),
            (GoalReward(), 25.0),
        )
    if table in ("simple", "simple_progress1"):
        return CombinedReward(
            (VelocityPlayerToBall(), 0.6),
            (VelocityBallToGoal(attacked=True), 0.08 if table == "simple" else 1.0),
            (GoalReward(), 25.0),
        )
    if table == "previous":
        return CombinedReward(
            (VelocityPlayerToBall(), 0.7),
            (VelocityBallToGoal(attacked=True), 1.0),
            (TangentialGoalShotReward(post_y_limit=65.0, scale=3.0), 3.0),
            (DeltaBreakawayReward(mult=2.0), 2.0),
            (PenaltyTackleLostReward(penalty=-0.5), 1.0),
            (GoalReward(), 20.0),
        )
    raise ValueError(f"Unknown reward table: {table}")


def create_training_env(
    n_envs: int, n_red: int, n_blue: int, stadium: str | None, tick_skip: int,
    seed: int | None = None, table: str = "corrected", repeat_kick: bool = True, approach_weight: float = 0.15,
):
    """Creates training environment with auto-calibrated obs_builder and multi-scenario resets."""
    engine = TransitionEngine(n_envs, n_red, n_blue, step_limit=2000, tick_skip=tick_skip, stadium=stadium)
    obs_builder = DefaultObs(pos_coef="auto")
    mutator = MultiSetter(
        [KickoffSetter(), RandomStateMutator(ball_speed=3.0, rng=seed)],
        weights=[0.4, 0.6],
        rng=seed,
    )
    return Env(
        engine=engine,
        obs_builder=obs_builder,
        action_parser=RepeatKickAction() if repeat_kick else DiscreteAction(kick_values=2),
        reward_fn=build_reward(table, stadium, tick_skip, approach_weight),
        termination_cond=GoalCondition(),
        truncation_cond=TimeoutCondition(2000),
        state_mutator=mutator,
    )


def create_eval_env(
    n_envs: int, n_red: int, n_blue: int, stadium: str | None, tick_skip: int,
    table: str = "corrected", repeat_kick: bool = True, approach_weight: float = 0.15,
):
    """Creates evaluation environment with standard kickoff resets."""
    engine = TransitionEngine(n_envs, n_red, n_blue, step_limit=2000, tick_skip=tick_skip, stadium=stadium)
    obs_builder = DefaultObs(pos_coef="auto")
    mutator = KickoffSetter()
    return Env(
        engine=engine,
        obs_builder=obs_builder,
        action_parser=RepeatKickAction() if repeat_kick else DiscreteAction(kick_values=2),
        reward_fn=build_reward(table, stadium, tick_skip, approach_weight),
        termination_cond=GoalCondition(),
        truncation_cond=TimeoutCondition(2000),
        state_mutator=mutator,
    )


@torch.no_grad()
def eval_vs_chase(eval_env, model, dev, n_red, n_blue, steps=350):
    """Net goals of model (red) vs ChaseBot (blue) over persistent eval_env."""
    obs = eval_env.reset()
    chase = ChaseBot(seed=0)
    P, od = n_red + n_blue, obs.shape[-1]
    n_envs = eval_env.engine.n_envs
    red_i, blue_i = np.arange(n_red), np.arange(n_red, P)
    rg = bg = 0
    for _ in range(steps):
        red = model.act(torch.as_tensor(obs[:, red_i].reshape(-1, od), dtype=torch.float32, device=dev))
        full = np.empty((n_envs, P, 3), dtype=np.int64)
        full[:, red_i] = red.cpu().numpy().reshape(n_envs, n_red, 3)
        full[:, blue_i] = chase.act(eval_env.prev_state, blue_i, n_red=n_red)
        obs, rew, term, trunc = eval_env.step(full)
        sc = eval_env.prev_state.scored
        rg += int((sc == BLUE).sum())  # blue conceded -> red scored
        bg += int((sc == RED).sum())
    return rg - bg

        best=baseline_score if baseline_score is not None else -1.
        torch.save(snapshot(),out/'model.pt')
        (out/'meta.json').write_text(json.dumps(dict(config, it=0, evaluation_score=baseline_score)))

        for it in range(1, args.iters + 1):
            iteration_start=time.perf_counter()
            meter.clear()
            telemetry.update(phase="rollout",iteration=it,rollout_step=0)
            frac = (it - 1) / max(1, args.iters - 1)
            for g in opt.param_groups:
                g["lr"] = LR * (1 - frac) + (LR / 3) * frac
            ent_coef = ENT0 * (1 - frac) + ENT1 * frac

            # pick frozen opponent: current copy or past snapshot
            opp.load_state_dict(
                pool[rng.integers(len(pool))] if (pool and rng.random() < POOL_PROB) else snapshot()
            )

            # --- rollout ---
            for t in range(T):
                o = torch.as_tensor(obs, dtype=torch.float32, device=dev)
                with torch.no_grad():
                    act, logp, val = model.act_train(o[learner_t])
                    o_act = opp.act(o[opp_t])
                S_obs[t], S_act[t], S_logp[t], S_val[t] = o[learner_t], act, logp, val
                full = np.empty((args.envs * P, 3), dtype=np.int64)
                full[learner_idx] = act.cpu().numpy()
                full[opp_idx] = o_act.cpu().numpy()
                nobs, rew, term, trunc = env.step(full.reshape(args.envs, P, 3))
                obs = nobs.reshape(args.envs * P, obs_dim)
                done = np.repeat((term | trunc).astype(np.float32), P)
                S_rew[t] = torch.as_tensor(rew.reshape(-1)[learner_idx], dtype=torch.float32, device=dev)
                S_done[t] = torch.as_tensor(done[learner_idx], device=dev)
                if (t+1)%8==0:
                    telemetry.update(phase='rollout',rollout_step=t+1)

            rollout_seconds=time.perf_counter()-iteration_start
            telemetry.update(phase="updating")
            # --- GAE advantages ---
            with torch.no_grad():
                last_val = model._logits(torch.as_tensor(obs, dtype=torch.float32, device=dev)[learner_t])[1]
            adv = torch.zeros(T, B, device=dev)
            gae = torch.zeros(B, device=dev)
            for t in reversed(range(T)):
                nonterm = 1.0 - S_done[t]
                nextval = last_val if t == T - 1 else S_val[t + 1]
                delta = S_rew[t] + gamma * nextval * nonterm - S_val[t]
                gae = delta + gamma * LAM * nonterm * gae
                adv[t] = gae
            ret = adv + S_val

            # --- PPO update ---
            bo, ba, bl = S_obs.reshape(-1, obs_dim), S_act.reshape(-1, 3), S_logp.reshape(-1)
            badv, bret = adv.reshape(-1), ret.reshape(-1)
            badv = (badv - badv.mean()) / (badv.std() + 1e-8)
            idx = np.arange(T * B)
            mb = len(idx) // N_MB
            ppo_metrics=[]
            for _ in range(EPOCHS):
                np.random.shuffle(idx)
                for s in range(0, len(idx), mb):
                    mi = torch.as_tensor(idx[s : s + mb], device=dev)
                    logp, ent, val = model.evaluate(bo[mi], ba[mi])
                    ratio = (logp - bl[mi]).exp()
                    a = badv[mi]
                    pl = -torch.min(ratio * a, torch.clamp(ratio, 1 - CLIP, 1 + CLIP) * a).mean()
                    vl = 0.5 * (val - bret[mi]).pow(2).mean()
                    loss = pl + VF_COEF * vl - ent_coef * ent.mean()
                    opt.zero_grad()
                    loss.backward()
                    nn.utils.clip_grad_norm_(model.parameters(), MAX_GRAD)
                    opt.step()
                    with torch.no_grad():
                        lr_delta=logp-bl[mi]
                        kl=((lr_delta.exp()-1)-lr_delta).mean()
                        clipped=((ratio-1).abs()>CLIP).float().mean()
                        ppo_metrics.append([float(pl),float(vl),float(ent.mean()),float(kl),float(clipped)])

            iteration_seconds=time.perf_counter()-iteration_start
            train_seconds+=iteration_seconds
            means=np.mean(ppo_metrics,axis=0)
            yvar=float(bret.var(unbiased=False))
            explained=1-float((bret-S_val.reshape(-1)).var(unbiased=False))/yvar if yvar>1e-9 else None
            record=dict(iteration=it,samples=it*T*B,iteration_seconds=iteration_seconds,
               rollout_seconds=rollout_seconds,update_seconds=iteration_seconds-rollout_seconds,
               samples_per_second=T*B/iteration_seconds,training_samples_per_second=it*T*B/train_seconds,
               wall_samples_per_second=it*T*B/(time.perf_counter()-t0),
               reward_mean=float(S_rew.mean()),reward_terms_per_sample={k:v/(T*B) for k,v in meter.sums.items()},
               reward_terms_absolute_per_sample={k:v/(T*B) for k,v in meter.absolute_sums.items()},
               goals_for=meter.gf,goals_against=meter.ga,completed_episodes=meter.finished,
               stationary_fraction=meter.stationary/max(1,meter.transitions),
               policy_loss=float(means[0]),value_loss=float(means[1]),entropy=float(means[2]),
               approximate_kl=float(means[3]),clip_fraction=float(means[4]),explained_variance=explained,
               learning_rate=opt.param_groups[0]['lr'],snapshot_pool=len(pool))
            telemetry.append('training.jsonl',record)
            telemetry.update(completed_iterations=it,samples=it*T*B,phase='checkpoint',last_training=record)

            if it % SNAPSHOT_EVERY == 0:
                pool.append(snapshot())
                if len(pool) > POOL_SIZE:
                    pool.pop(0)

                torch.save(model.state_dict(), out / "ckpts" / f"it{it}.pt")

                meta=dict(config,it=it,evaluation_score=score)
                torch.save(snapshot(),out/'model_final.pt')
                (out/'meta_final.json').write_text(json.dumps(meta))

def resolve(arg: str | None) -> tuple[Path, dict]:
    """Return (state_dict_path, meta). `arg` may be None (default), a run-dir name, or a .pt."""
    if arg is None:
        meta_path = CKPT / "meta.json"  # optional — obs_dim/depth are inferred from the weights
        meta = json.loads(meta_path.read_text()) if meta_path.exists() else {}
        return CKPT / "model.pt", meta
    p = Path(arg)
    if p.suffix == ".pt":  # explicit checkpoint file
        sd_path = p if p.is_absolute() else (HERE.parent / p)
        meta_path = sd_path.parent / "meta.json"
    else:  # a run-dir name under checkpoints/ — prefer the deploy weights (model_final.pt)
        run = CKPT / arg
        sd_path = run / "model_final.pt"
        if not sd_path.exists():
            sd_path = run / "model.pt"
        meta_path = run / "meta.json"
    if not meta_path.exists() and sd_path.parent.name == "ckpts":
        meta_path = sd_path.parent.parent / "config.json"
    meta = json.loads(meta_path.read_text()) if meta_path.exists() else {}
    return sd_path, meta


def stadium_obs_params(stadium: str) -> tuple[list[float], float, str | None]:
    """Map-aware obs scaling for bot.js: (pos_coef [px,py], goal_x, stadium_hbs|None).
    Mirrors haxballgym's DefaultObs(pos_coef='auto') so the room obs matches training."""
    from haxballgym.obs import DefaultObs
    from haxballgym.stadium import stadium_text

    from haxballgym import TransitionEngine

    is_classic = stadium in ("", "classic")
    eng = TransitionEngine(1, 1, 1, stadium=None if is_classic else stadium)
    ob = DefaultObs(pos_coef="auto")
    ob.reset(eng.snapshot())
    goal_x = float(max(abs(eng._goal_p0[:, 0]).max(), abs(eng._goal_p1[:, 0]).max()))
    hbs = None if is_classic else stadium_text(stadium)
    return [float(ob.pos_coef[0]), float(ob.pos_coef[1])], goal_x, hbs


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("ckpt", nargs="?", default=None)
    ap.add_argument("--stadium", default=None, help="override; else meta.stadium, else classic")
    args = ap.parse_args()

    sd_path, meta = resolve(args.ckpt)
    sd = torch.load(sd_path, map_location="cpu")
    obs_dim = meta.get("obs_dim") or sd["trunk.0.weight"].shape[1]
    depth = sum(1 for k in sd if k.startswith("trunk.") and k.endswith(".weight"))
    if obs_dim != 16 or depth != 2:
        raise SystemExit(
            f"refusing to export: bot.js's buildObs produces the 16-dim DefaultObs (1v1, depth-2 MLP) "
            f"only, but this checkpoint is obs_dim={obs_dim}, depth={depth}. Deploying it would feed a "
            f"truncated obs into the policy (silently wrong forward pass). Extend bot.js's buildObs to "
            f"match this obs (PredictObs/GeoObs/SharedObs/action_stack/team size) before exporting."
        )

    stadium = args.stadium or meta.get("stadium") or "classic"
    pos_coef, goal_x, hbs = stadium_obs_params(stadium)

    def mat(key):  # weight (out, in) and bias (out,) as plain nested lists
        return {"w": sd[f"{key}.weight"].tolist(), "b": sd[f"{key}.bias"].tolist()}

    name = sd_path.parent.name if sd_path.name == "model_final.pt" else sd_path.stem
    if name in ("checkpoints", ""):
        name = sd_path.stem
    policy = {
        "obs_dim": obs_dim,
        "repeat_kick": bool(meta.get("repeat_kick", False)),
        "name": name,
        "stadium_name": stadium,
        "pos_coef": pos_coef,  # [px, py] obs position scale — map-aware (DefaultObs 'auto')
        "goal_x": goal_x,  # goal-line x for target/own-goal-rel obs terms
        "stadium_hbs": hbs,  # .hbs text for non-classic maps -> bot.js setCustomStadium; null on classic
        "trunk0": mat("trunk.0"),
        "trunk2": mat("trunk.2"),
        "head_x": mat("head_x"),
        "head_y": mat("head_y"),
        "head_k": mat("head_k"),
    }
    out = HERE / "policy.json"
    out.write_text(json.dumps(policy))
    print(
        f"wrote {out.name} from {sd_path.relative_to(HERE.parent)} | obs_dim={obs_dim} "
        f"stadium={stadium} pos_coef={[round(c, 5) for c in pos_coef]} goal_x={goal_x:.0f}"
    )


if __name__ == "__main__":
    main()

function linear(x, layer) {
  const out = new Array(layer.b.length);
  for (let i = 0; i < out.length; i++) {
    let sum = layer.b[i];
    const row = layer.w[i];
    for (let j = 0; j < x.length; j++) sum += row[j] * x[j];
    out[i] = sum;
  }
  return out;
}
const tanh = (a) => a.map(Math.tanh);
const argmax = (a) => a.reduce((best, v, i, arr) => (v > arr[best] ? i : best), 0);

function act(obs) {
  let h = tanh(linear(obs, P.trunk0));
  h = tanh(linear(h, P.trunk2));
  const kickVal = argmax(linear(h, P.head_k)); // 0=release, 1=hold, 2=rocket (3-way heads only)
  return {
    dx: argmax(linear(h, P.head_x)) - 1, // {0,1,2} -> {-1,0,1}
    dy: argmax(linear(h, P.head_y)) - 1,
    kick: kickVal >= 1,
    rocket: kickVal === 2, // rapid-fire: re-kick every tick
  };
}

// Goal-relative, side-aware observation — identical to haxballgym DefaultObs.
// CRITICAL: DefaultObs MIRRORS the x-axis for blue (so both teams see "attacking +x" and one
// net plays both sides). We must apply the SAME mirror here — `sx = -1` for blue negates every
// x-component — or a blue bot gets left/right inverted and runs the wrong way. The action's dx
// is un-mirrored by the same `sx` in controlBot (matches env.py `engine_actions[...,0]*=mirror`).
function buildObs(self, ball, opp, team) {
  const fy = CONFIG.flipY ? -1 : 1;
  const sx = team === RED ? 1 : -1; // blue x-mirror, matching DefaultObs (out[...,0::2] *= sx)
  const targetX = team === RED ? GOAL_X : -GOAL_X; // attacked goal in WORLD: red +x, blue -x
  return [
    sx * self.pos.x * PX, self.pos.y * fy * PY,
    sx * self.speed.x * VS, self.speed.y * fy * VS,
    sx * (ball.pos.x - self.pos.x) * PX, (ball.pos.y - self.pos.y) * fy * PY,
    sx * ball.speed.x * VS, ball.speed.y * fy * VS,
    sx * (targetX - self.pos.x) * PX, -self.pos.y * fy * PY,
    sx * (-targetX - self.pos.x) * PX, -self.pos.y * fy * PY,
    sx * (opp.pos.x - self.pos.x) * PX, (opp.pos.y - self.pos.y) * fy * PY,
    sx * opp.speed.x * VS, opp.speed.y * fy * VS,
  ];
}

function controlBot(room) {

      after(() => {
        room.fakeSendPlayerInput(lastKey & ~16, BOT_ID);

  const sx = me.team.id === RED ? 1 : -1;

    const tbx = Math.sign(ball.pos.x - self.pos.x), tby = Math.sign(ball.pos.y - self.pos.y);
    const d = Math.hypot(ball.pos.x - self.pos.x, ball.pos.y - self.pos.y);

  switch (cmd) {
    case "restart": after(() => { room.stopGame(); room.startGame(); }); break;
    case "start": after(() => room.startGame()); break;
    case "stop": after(() => room.stopGame()); break;
    case "swap": // swap the bot and you between teams
      after(() => {
        const me = humans(room)[0];
        const botTeam = room.getPlayer(BOT_ID).team.id;
        room.setPlayerTeam(BOT_ID, botTeam === RED ? BLUE : RED);
        if (me) room.setPlayerTeam(me.id, botTeam === RED ? RED : BLUE);
      });
      break;
    case "reload": // hot-swap the bot's weights from policy.json — no room restart

        reloadPolicy();

      } catch (e) {

function linear(x, layer) {
  const out = new Array(layer.b.length);
  for (let i = 0; i < out.length; i++) {
    let sum = layer.b[i];
    const row = layer.w[i];
